# ❄️ Hautes-Alpes Weather & Climate Dashboard

An interactive weather and climate dashboard analyzing historical data from the **Hautes-Alpes** department in France, built as an academic web development project.

> **Primary Objective:** Visualize the impact of climate change in alpine regions by processing, filtering, and representing large meteorological datasets using interactive maps and data visualization libraries.

---

## 💡 Project Overview

This application tackles the challenge of digesting massive raw datasets to display clear, meaningful climate insights. Users can explore various weather stations across the Hautes-Alpes region to observe long-term environmental shifts.

### Key Features
- 🗺️ **Interactive Station Map:** Select weather stations across the Hautes-Alpes department using an interactive **Leaflet.js** map.
- ❄️ **Annual Snowfall Chart:** Visualize year-over-year snowfall trends to track winter duration and intensity changes.
- 🌡️ **Annual Temperature Chart:** Display historical temperature evolutions to highlight regional warming patterns.
- 📊 **Data Filtering & Aggregation:** Processed large SQL datasets to extract only the most relevant climate indicators.
